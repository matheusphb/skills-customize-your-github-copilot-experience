# 📘 Assignment: Games in Python — Hangman

## 🎯 Objective

Build a Hangman game in Python to practice strings, loops, conditionals, and user input while managing game state.

## 📝 Tasks

### 🛠️	Set up the game and word selection

#### Description
Create the initial game setup, including a list of possible words and randomly choosing one hidden word for the round.

#### Requirements
Completed program should:

- Store at least 5 possible words in a list
- Randomly select one word at the start of the game
- Initialize the display as underscores separated by spaces (e.g., _ _ _)


### 🛠️	Implement guessing and win/lose logic

#### Description
Let the player guess letters, update the display, and track remaining attempts until the game ends.

#### Requirements
Completed program should:

- Accept single-letter guesses from the player
- Reveal correctly guessed letters in the display
- Decrease remaining attempts for incorrect guesses
- End the game when the word is fully guessed or attempts reach zero
- Print a clear win or lose message at the end
